
## Цель работы

Добавить к каталогу пород собак интерактивные функции на JavaScript: поиск, фильтрацию, сортировку, добавление и удаление записей, а также сохранение данных в браузере.

## Ход работы

В качестве основы использован проект каталога пород собак из лабораторной работы № 1. Версия для лабораторной работы № 2 подготовлена отдельно в папке `mira`.

В каталоге реализован поиск по названию породы, описанию и категории. Поиск обновляет список при вводе текста и не зависит от регистра букв. Добавлен фильтр по категориям: служебные, охотничьи, пастушьи и декоративные. Пункт «Все категории» сбрасывает фильтр.

Список можно сортировать по названию в прямом и обратном алфавитном порядке, а также по времени добавления. Сортировка выполняется для копии массива, поэтому исходный список не изменяется.

Для добавления породы создано модальное окно с формой. В форме указываются название, категория и описание. Обязательные поля и ограничения длины заданы HTML-атрибутами, а JavaScript проверяет состояние полей через Constraint Validation API. Окно закрывается крестиком, кнопкой отмены, клавишей Escape или нажатием на фон.

Удаление карточек реализовано через делегирование событий: один обработчик установлен на общий контейнер каталога. Метод `closest()` находит кнопку удаления, по которой пользователь нажал.

Данные приложения хранятся в объекте `state`. После изменения состояния функция `render()` заново формирует карточки и обновляет счётчик результатов. При добавлении и удалении список сохраняется в `localStorage` с помощью `JSON.stringify()`, а при открытии страницы загружается через `JSON.parse()`.

Пользовательские данные выводятся с помощью `textContent`, поэтому введённый текст отображается как текст и не интерпретируется как HTML.

## Результат

Каталог получил функции поиска, фильтрации, сортировки, добавления и удаления пород. Данные сохраняются между перезагрузками страницы в браузере. Интерфейс адаптируется к узким экранам.

## Вывод

В ходе лабораторной работы статическая страница каталога была дополнена интерактивной логикой на чистом JavaScript. На практике использованы работа с DOM и событиями, валидация формы, делегирование событий, `localStorage` и подход State-Driven UI.
