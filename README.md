# Породы собак — каталог

Главная страница веб-приложения-каталога пород собак. Лабораторная работа № 1: статическая клиентская часть на HTML и CSS.

## Для кого предназначен

Для людей, которые выбирают собаку и хотят познакомиться с популярными породами: каталог объединяет породы четырёх категорий — служебные, охотничьи, пастушьи и декоративные.

## Основные блоки страницы

- **Шапка** — название проекта и навигация по категориям.
- **Баннер-приветствие** — краткое объяснение, какую задачу решает проект.
- **Каталог** — 8 карточек пород с фотографией, категорией, названием и кратким описанием.
- **Подвал** — название проекта и дополнительная информация.

## Технологии

- HTML5 (семантические элементы: `header`, `nav`, `main`, `section`, `footer`)
- CSS3: CSS Grid — сетка карточек, Flexbox — шапка и навигация
- Без JavaScript (добавляется в следующих лабораторных)

## Как открыть

Скачайте репозиторий и откройте `index.html` в браузере — дополнительная настройка не требуется.

## Структура проекта

```text
├── index.html      — главная страница (разметка + стили)
├── README.md
└── img/            — фотографии пород (сгенерированы, единый стиль)
```

## Источники изображений

Все фотографии пород сгенерированы нейросетью специально для проекта; внешние источники не используются.
