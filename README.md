# Каталог пород собак — лабораторная работа № 2

Интерактивная версия проекта [Dog_catalog](https://github.com/SamiraNasypova23/Dog_catalog). Страница сделана на обычных HTML, CSS и JavaScript — дополнительные библиотеки не нужны.

## Как открыть

Откройте `index.html` в браузере. Фотографии загружаются из открытого репозитория, поэтому для них нужен интернет. Записи, которые вы добавляете, сохраняются в `localStorage` этого браузера.

## Что реализовано

- Живой поиск по названию, описанию и категории без учёта регистра.
- Фильтр по четырём категориям и пункт «Все категории».
- Сортировка по названию в двух направлениях и по времени добавления.
- Модальное окно добавления породы. Оно закрывается крестиком, кнопкой «Отмена», клавишей Escape и щелчком по фону.
- Проверка формы через HTML-атрибуты и `input.validity`.
- Удаление карточки одним обработчиком на общей сетке (`closest()`).
- Сохранение записей через `JSON.stringify()` и загрузка через `JSON.parse()`.
- Состояние хранится в объекте `state`; функция `render()` заново строит карточки из состояния.

## Коротко для защиты

- **State-Driven UI:** сначала меняем данные в `state`, затем вызываем `render()`. Экран всегда строится из текущего состояния.
- **`filter()` и `sort()`:** фильтр выбирает подходящие породы, сортировка применяется к копии массива, чтобы не менять исходный список.
- **Делегирование:** событие всплывает от кнопки удаления до общей сетки. `closest()` находит кнопку, поэтому обработчик не нужен на каждой карточке.
- **`preventDefault()`:** отменяет обычную отправку формы и перезагрузку страницы.
- **`localStorage`:** хранит только строки, поэтому массив превращается в JSON и обратно.
- **`textContent`:** показывает текст пользователя как текст, не выполняя введённую HTML-разметку.
- **`const` и `let`:** `const` используют для ссылок, которые не переназначаются, `let` — для переменных с новым значением. `var` не используется.
